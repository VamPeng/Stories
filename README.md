## 文档约定

- 文件名统一为 `<概念>.md`。
- 正文使用简体中文。
- 结构包含：寓言故事、概念介绍、关键机制或公式、典型应用、故事映射。
- 公式优先使用 Unicode 与纯文本代码块，避免依赖可能在语雀导入时失效的 LaTeX 定界符。
- 每次新增故事时同步更新本 README 的概念列表。
